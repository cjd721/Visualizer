# Visualizer

Visualizer turns a code project into a **Blueprint**: an interactive, layered picture of what the project is made of and how its parts connect. Next to it you can chat with **Mason**, an AI guide who explains what you click and turns your decisions into issues for your coding agent.

It's built for non-technical builders to conceptualize and learn about what you're building.
